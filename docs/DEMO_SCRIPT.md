# Five-minute review demo

Before the review: `docker compose up --build`, wait for MongoDB and server health, then `docker compose exec server npm run seed`. Open http://localhost:8080. This demo explicitly permits private webhook targets; do not expose the stack to the internet.

1. **0:00–0:45 — Build visually.** In the editor open Templates and load Turbine Overheat Alert, or drag a sensor, moving average, threshold and actions onto the canvas and connect them. Explain device, sensor type, moving window, threshold, message template and cooldown. Use auto-layout, undo/redo and Save. Activate a saved valid graph.
2. **0:45–1:45 — Run live.** Click Run Demo. It loads and activates the turbine template and starts the built-in simulator for two minutes. The split view shows the chart and alert feed. Normal wires pulse blue/cyan; once the moving average crosses the threshold the alert path glows red. Toggle Live Mode off/on. For independent simulated devices use `cd server && npm run simulate -- --url http://localhost:8080 --devices 10 --interval 1000`; stop with Ctrl+C.
3. **1:45–2:45 — Audit.** Open Alerts. Filter by graph or device; show delivery status and the Deliveries tab. The local webhook and mock SMS should succeed. Open Mock Receiver to inspect the payload. For retry, use a safe unreachable public webhook, wait for a failed delivery, fix the destination externally and use Retry; retries replay the original saved request, not edited node settings. Stop Demo when done.
4. **2:45–3:30 — Dashboard.** Show the time-series chart, recent alerts and engine counters. Explain that the telemetry bus routes readings to compiled RxJS pipelines, with node cooldown and per-graph outbound limits.
5. **3:30–4:30 — Throughput and footprint.** In `server`, run `npm run benchmark -- --url http://localhost:8080 --requests 100 --batch-size 100 --concurrency 10`. Report the actual measured accepted writes/sec and failures, not a promised rate. Inspect storage with `docker compose exec mongo mongosh nexusflow --quiet --eval 'printjson(db.telemetries.stats())'` (verify the collection name with `show collections`). Compare logical size and storage size and explain time-series compression.
6. **4:30–5:00 — Review and limits.** Show the graph-to-stream architecture, SSRF default protection, retry audit and mock provider. Disclose that the queue, active graphs and cooldown are in-memory and APIs lack user authentication; discuss durable workers, event streaming and RBAC as next steps.
